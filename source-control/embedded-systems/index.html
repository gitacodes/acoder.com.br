Embedded Systems & Hardware

This collection groups the repositories that best represent Nicolas Pereira’s work across microcontrollers, embedded software, control systems, and IoT fundamentals. The original source material mixed Portuguese notes and partial links; this version consolidates the public GitHub references into a cleaner English overview.

Featured Repositories

  • 8-bit MCU
    Projects built with 8-bit Microchip PIC microcontrollers, including access control, queue management, fixed-frequency generation, PWM generation, and fault-analysis experiments for frequency inverters.

  • Embedded Operating Systems
    Embedded exercises for ESP32 and Arduino covering digital and analog I/O, timers, interrupts, object-oriented embedded design, and FreeRTOS task coordination.

  • Control Systems
    Coursework and experiments around transfer functions, system stability, root locus analysis, and DC motor modeling using Octave, Python, and notebooks.

  • Internet of Things
    IoT activities using ESP8266, ESP32, and Arduino, with examples for timers, LDR sensors, DHT11 data collection, Wi-Fi connectivity, and ThingSpeak publishing.
